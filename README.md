# Lịch Học Hè (Summer Schedule)

Website quản lý lịch học mùa hè cho con - responsive trên web và điện thoại.

## Features

- **Quản lý môn học**: Thêm/sửa/xóa môn (cố định/linh hoạt)
- **Lịch cố định**: Nhập lịch các môn có giờ cố định
- **Sự kiện đặc biệt**: Đánh dấu ngày nghỉ, đi chơi
- **Auto-schedule**: Tự động phân bổ môn linh hoạt vào slot trống
- **Tracking**: Đánh dấu hoàn thành, ghi chú
- **Báo cáo**: Ngày/Tuần/Tháng - tiến độ %, tổng giờ học

## Tech Stack

- HTML/CSS/JS thuần (Vanilla)
- LocalStorage cho lưu trữ
- Mobile-first responsive design
- No build step required

## Quick Start

```bash
# Option 1: Python
python -m http.server 8000

# Option 2: Node.js
npx serve .

# Then open http://localhost:8000
```

## Deploy

Push to `main` branch → Auto deploy to GitHub Pages.
